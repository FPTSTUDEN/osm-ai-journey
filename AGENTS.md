# Repository Agent Instructions

## Commits

- Keep commit messages concise and natural. For substantial changes, use a short `What I wanted:` section to summarize the user's goals or decisions discussed in the conversation. Focus on intent and constraints, not implementation details; skip the section for small changes.
- Use the repository owner's GitHub identity as the commit author: `FPTSTUDEN <126749897+FPTSTUDEN@users.noreply.github.com>`.
- Include the OpenCode agent as a co-author on commits:
  `Co-authored-by: opencode-agent[bot] <opencode-agent[bot]@users.noreply.github.com>`.
